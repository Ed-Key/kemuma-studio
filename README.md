# Kemuma Studio

Cataloging pipeline for [Kemuma Carvings](https://www.etsy.com/shop/KemumaCarvings), a collection of vintage soapstone sculptures hand-carved by my grandparents in Tabaka, Kisii, Kenya in the 1990s.

Photos of a piece go in; cleaned images, drafted listing copy, tags, pricing, and an Etsy draft listing come out. Every draft passes through a human review screen before it touches the shop, and every correction made there feeds an eval harness measured on the real catalog.

Early development. Design doc: [docs/superpowers/specs/2026-07-23-kemuma-studio-design.md](docs/superpowers/specs/2026-07-23-kemuma-studio-design.md).
